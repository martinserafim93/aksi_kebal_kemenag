# Daftar Perbaikan dan Peningkatan UI (Bug & Styling)

Berikut adalah daftar isu yang perlu diperbaiki pada modul-modul CRUD admin:

## 1. Manajemen User (Pegawai)
- **Bug:** Fitur hapus pegawai tidak berfungsi (tidak merespon atau gagal).
- **UI/UX:** Tombol "Tambah Pegawai" kurang menarik. Seharusnya diberikan *highlight* yang sesuai dengan tema aplikasi (misalnya menggunakan warna primer atau gradien yang mencolok).
- **UI/UX:** Tombol "Simpan Pegawai" dan "Simpan Perubahan" kurang menarik. Perlu disesuaikan gayanya agar lebih menonjol dan serasi dengan tema desain.

## 2. Manajemen Tim Kerja
- **Bug:** Fitur hapus tim kerja tidak berfungsi.
- **UI/UX:** Tombol "Tambah Tim Kerja" kurang menarik. Harus diberikan *highlight* sesuai tema.
- **UI/UX:** Tombol "Simpan Tim Kerja" dan "Simpan Perubahan" kurang menarik, perlu peningkatan visual.

## 3. Manajemen Jabatan
- **Bug:** Fitur hapus jabatan tidak berfungsi.
- **UI/UX:** Tombol "Tambah Jabatan" kurang menarik. Harus diberikan *highlight* sesuai tema.
- **UI/UX:** Tombol "Simpan Jabatan" dan "Simpan Perubahan" kurang menarik, perlu disesuaikan dengan tema visual aplikasi.
