# AKSI KEBAL

**A**bsensi **K**egiatan **S**erentak **K**ementerian **B**eramal dan **A**ndal (AKSI KEBAL) merupakan sistem informasi mencerminkan kedisiplinan dan akhlak baik pegawai dalam mengikuti kegiatan.  
Terinspirasi dari semboyan khas Kemenag "Ikhlas Beramal", menggambarkan absensi yang kuat dan terintegrasi.
